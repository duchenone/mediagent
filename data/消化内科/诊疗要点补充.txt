# 消化内科诊疗要点补充

> 整理自《常见疾病诊疗100问》《诊断规范与治疗指南》，补充消化内科核心知识要点。

## 一、消化性溃疡（Q14 + 诊断规范§三 腹痛）

### 典型临床表现
上腹部**节律性疼痛**：
- **十二指肠溃疡**：饥饿痛（餐后2-3小时）→进食缓解
- **胃溃疡**：餐后痛（餐后0.5-1小时）
- 伴随症状：反酸、嗳气、恶心

### NSAIDs相关性溃疡
见《消化性溃疡诊疗》中的预防策略（PPI共处方、COX-2选择、米索前列醇等）。

## 二、急性胰腺炎（Q15）

### 诊断标准（满足≥2项）
1. 急性发作的持续性上腹部剧烈疼痛，常向背部放射
2. 血清淀粉酶和/或脂肪酶≥正常上限3倍
3. 腹部影像学（CT/MRI/超声）显示胰腺炎特征性改变

## 三、肝硬化并发症（Q16）

食管胃底静脉曲张破裂出血、自发性细菌性腹膜炎（SBP）、肝性脑病、肝肾综合征（HRS）、肝细胞癌（HCC）、门静脉血栓形成。

## 四、急性阑尾炎（Q17）

转移性右下腹痛（脐周/上腹→数小时后转移至右下腹），麦氏点（McBurney点）压痛+反跳痛，伴恶心呕吐、低热。

## 五、胃食管反流病 GERD（Q18）

**特征症状**：烧心（胸骨后烧灼感）+ 反流（胃内容物向咽部/口腔流动）
**食管外症状**：胸痛（非心源性）、吞咽困难、慢性咳嗽、咽喉不适

## 六、腹痛诊断流程（诊断规范§三）

### 定位与器官对应
| 部位 | 对应器官 |
|------|----------|
| 右上腹 | 肝、胆道、十二指肠、右肾 |
| 上腹部 | 胃、十二指肠、胰腺、横结肠 |
| 左上腹 | 脾、胰腺尾部、左肾 |
| 右下腹 | 阑尾、盲肠、右附件（女） |
| 脐周 | 小肠、肠系膜 |
| 左下腹 | 乙状结肠、左附件（女） |
| 下腹部 | 膀胱、子宫（女） |

### Red Flags（危险信号）
- 突发剧烈腹痛（穿孔/夹层/破裂）
- 腹膜炎体征（腹肌紧张、压痛、反跳痛）
- 休克表现
- 呕血/便血/黑便
- 妊娠可能（异位妊娠破裂）
- 高龄>70岁
- 免疫抑制状态

### 影像学选择
- 立位腹平片：穿孔（膈下游离气体）、肠梗阻（气液平）
- 超声：胆囊炎、胆道结石、阑尾炎、妇科急症
- CT：实质脏器损伤、胰腺炎、脓肿、肿瘤、血管病变
- 增强CT：血管性病变（主动脉夹层、肠系膜缺血）

## 七、肝功能指标解读（Q67）

| 指标 | 意义 |
|------|------|
| ALT | 肝细胞浆，肝细胞损伤时升高 |
| AST | 肝细胞线粒体，严重损伤时AST>ALT |
| GGT | 胆道疾病、酒精性肝病 |
| ALP | 胆道梗阻、骨骼疾病 |
| TBil/DBil | 黄疸分类依据 |

## 八、癌痛三阶梯止痛（Q43）

（消化系统肿瘤疼痛管理参考）
- 第一阶梯（轻度）：NSAIDs±辅助药
- 第二阶梯（中度）：弱阿片类（曲马多/可待因）±NSAIDs±辅助药
- 第三阶梯（重度）：强阿片类（吗啡/芬太尼）±NSAIDs±辅助药
